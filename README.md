                             📊📈 Retail Sales & Returns Performance Analysis 📊📈

An interactive Tableau project designed to analyze sales performance, revenue contribution, unit sales, regional trends, sales representative performance, and returned orders using the Global Superstore dataset.

📌 Project Overview

This project analyzes retail sales data using Tableau and Excel to understand sales performance across different regions, countries, products, and sales representatives.

The analysis combines data from three related tables:

• 🛒 Orders
• 🔄 Returns
• 👥 People

The project contains 51,290 order records covering 147 countries and 13 regions.

The analysis focuses on identifying sales trends, measuring revenue and unit performance, analyzing returned orders, and understanding geographical sales patterns.

🎯 Project Objectives

• Analyze regional sales performance
• Measure revenue generated by sales representatives
• Analyze units sold across different regions
• Compare sales representative performance
• Analyze product-level revenue across geographic regions
• Identify year-over-year revenue trends
• Identify returned orders
• Calculate the proportion of returned orders
• Analyze sales performance geographically
• Create an interactive Tableau dashboard with multiple visualizations

📊 Tableau Analysis

The project includes multiple visualizations for analyzing sales performance.

📈 Region-Wise Sales

A bar chart is used to compare total sales across different regions and identify regions with higher and lower sales performance.

👥 Sales Representative Performance

Sales representatives are analyzed based on:

• 💰 Total revenue contributed
• 📦 Number of units sold

The analysis identified:

🏆 Anna Andreadi as the sales representative with the highest sales and highest quantity sold.

📦 Units Sold by Region

The analysis compares total item volumes sold across different regions under each sales representative.

This helps identify differences in sales volume and representative performance across geographic regions.

📋 Product Revenue by Region

A highlight table is used to analyze revenue generated by individual products across geographic regions.

This provides a detailed view of product-level revenue performance.

📅 Revenue Trend Analysis

Revenue trends are analyzed across different years and regions.

The project examines year-over-year revenue performance from:

📅 2011 → 2014

This helps identify changing regional sales patterns and underperforming regions.

🔄 Returns Analysis

Returned orders are analyzed using the Returns table.

📌 Key Finding

• 🔄 Return Rate: 4.7%
• 📦 Returned Orders: 1,173
• 📊 Total Orders Considered: 25,035

The analysis identifies which orders were returned and measures the overall proportion of returned orders.

🌳 Returned Order Visualization

A Tree Map is used to visualize returned orders.

The Returned field is used to distinguish returned and non-returned orders, allowing returned-order patterns to be explored visually.


🥧 Return Rate Analysis

A Pie Chart is used to visualize the proportion of orders that were returned.

This provides a quick overview of the relationship between returned and non-returned orders.

🌍 Geographic Analysis

A geographical hierarchy was created using:

Country → State → City → Postal Code

This hierarchy enables geographic analysis at multiple levels.

🗺️ Geographic Visualization

The geographic hierarchy is used to create a map-based visualization for analyzing sales and geographic distribution.
